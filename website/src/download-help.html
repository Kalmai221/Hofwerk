Which one do I pick?

Windows installer has the whole app inside and works without internet, so it is the safe choice. The online installer is a smaller file that downloads the app while it installs. Linux is one file for 64-bit desktops.

Install on Windows

  1. Run the file you downloaded. Hofwerk installs just for you, so no administrator rights are needed.
  2. Windows may say it protects your PC, because the installer is not code-signed yet. Choose More info, then Run anyway.
  3. Tell it where OMSI 2 is if it does not find it, and choose whether you want a desktop shortcut.
  4. Hofwerk starts when it is done. To remove it later, use Windows’ Installed apps.

You need Windows 10 (version 1809) or newer, 64-bit. If the standard version does not run on your computer, Hofwerk offers a second version when it hits an error.

Install on Linux

tar -xzf Hofwerk-Setup-*-linux-x64.tar.gz
./Hofwerk-Setup-*-linux-x64

It installs to ~/.local/share/hofwerk, adds Hofwerk to your applications menu and a hofwerk command. The menu entry has an Uninstall Hofwerk action. The Linux version is new and has not been tried on many desktops yet, so please tell me if something does not work.

Check your download

Each download shows its SHA-256. On Windows, Get-FileHash file.exe in PowerShell prints the same value; on Linux use sha256sum.

Updates

Once Hofwerk is installed it looks for new versions when it starts and updates itself from inside the app, so you only need this page once.
