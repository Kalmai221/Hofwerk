Everything you need for a depot file

Destinations, bus stops and routes

Edit everything in a .hof file, with the depot settings, folders and IBIS codes. A tick shows when a folder exists in your OMSI install, and problems in a file are listed for you.

Export to several folders

List the bus packs a file belongs in, saved in the file itself like HOF Suite does, and put it into all of them in one go, with a progress bar and a copy of anything it replaces.

Undo, redo and autosave

Take back any change, even after saving. Turn on autosave if you like, and Hofwerk asks before you close with work that is not saved.

Start from an OMSI map

Pick a map by its picture, like in OMSI, and Hofwerk fills in its bus stops, destinations and routes for a new file.

String presets

Name the string slots of your bus (“IBIS 1”, “ANNAX (side)”) instead of remembering what “String 7” means. Import a strings file of your own, or share one.

Updates itself

Hofwerk tells you when there is a new version and installs it from inside the app, with a “What’s new” for every version. Light and dark themes, and an error window with a ready-made bug report.

Made for the files you already have

Hofwerk reads and writes the same .hof files as HOF Suite, keeps their encoding, and understands the export list HOF Suite stored inside them. You can switch between the two whenever you like.

Why I made Hofwerk

HOF Suite is how most of the OMSI community learned to make .hof files without editing text by hand, and it has not been updated since 2019. It only runs on Windows, while more and more people play on Linux or a Steam Deck. I wanted an editor that feels like today’s software and works on both.

Linux gaming is growing: Valve’s Steam Hardware Survey had Linux at 2.64% in August 2025 and 3.90% in August 2026, and it passed 5% for the first time in March 2026. It moves from month to month and only counts Steam users who chose to answer, so it shows a direction, not an exact count.
